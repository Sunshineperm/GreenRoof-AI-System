    01

    影像识别与覆盖率

    当前支持 RGB / NIR 植被指数辅助识别、已有二值分割掩膜和项目测试集人工标注样例。支持本项目 BGRN TIFF，并保留地理参考与科学波段；第四波段作为近红外处理，不当作透明度。必须圈定屋顶范围，地面树木不纳入分母。RGB 阈值并非 GR-Net，辅助结果需要人工校核。

    C = N绿化屋顶 / N屋顶总范围 × 100%

    面积 = 原始影像像素数 × 空间分辨率²。计算使用原始分辨率；有效影像不超过 1600 万像素，支持常见压缩、16 位和浮点 GeoTIFF 的读取；显示拉伸不会更改温度原值。圆滑显示不改变统计结果。掩膜与原图须同尺寸、同坐标配准。

    02

    相关与显著性

    使用同日期、同统计尺度的覆盖率与平均地表温度配对数据。计算 Pearson r、双侧 p 值与 Fisher 变换的 95% 置信区间（n ≥ 4），并进行 Spearman 对照、IQR 异常值提示和分区域分析。常量数据、缺失值和重复单元会阻止计算。

    r = Σ(x−x̄)(y−ȳ) / √[Σ(x−x̄)² Σ(y−ȳ)²]

    显著性水平 α = 0.05，p 值使用 Pearson 零相关假设下的精确 Beta 分布。需满足独立样本及检验分布假设，空间聚集样本不一定独立。

    计算依据：SciPy Pearson 文档
    03

    四档缓解关联等级

    以下为本原型的可调项目规则，不是已验证的生态效益标准。评价负相关的强度和统计证据，不评价真实因果降温效果。

    等级默认判定（p < 0.05）
    优r ≤ −0.70
    良−0.70 < r ≤ −0.50
    及格−0.50 < r ≤ −0.30
    不及格弱负相关、不显著或正相关

    不足 3 个样本或不可计算时显示“待评估”，不强行给出等级。等级阈值会随报告导出。
